# ADR-000: Ideias futuras e TODO

- Status: Proposto
- Data: 2026-07-28

## Contexto

O projeto já possui a base funcional, mas ainda há oportunidades claras de melhoria para transformar a ferramenta em uma solução mais completa.

## TODO

Algumas ideias para evolução futura:

- permitir editar pontos já criados;
- carregar projetos salvos e continuar a edição;
- agrupar coordenadas por categorias ou camadas;
- exportar para outros formatos, como CSV ou TXT;
- adicionar suporte a múltiplas imagens em um mesmo projeto;
- melhorar a experiência visual com zoom, pan e remoção seletiva de pontos.

## Sugestão

Estas melhorias podem ser implementadas de forma incremental, sem comprometer a arquitetura modular atual.
