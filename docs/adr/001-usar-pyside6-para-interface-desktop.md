# ADR-001: Usar PySide6 para a interface desktop

- Status: Aceito
- Data: 2026-07-28

## Contexto

Era necessário criar uma ferramenta desktop simples para marcação visual de pontos sobre imagens, com interação direta via mouse e suporte a interface gráfica.

## Decisão

Utilizar PySide6 como framework principal para a interface gráfica da aplicação.

## Consequências

- Permite construir uma aplicação desktop de forma relativamente rápida.
- Mantém o projeto acessível para quem já conhece Python.
- Facilita a evolução para recursos visuais mais completos no futuro.
